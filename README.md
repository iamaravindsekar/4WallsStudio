# 4 Walls Studio - Bento type website

Responsive single-page static website with Lumia-inspired GSAP tile transitions.

## Files
- `index.html` — content and structure
- `styles.css` — responsive bento layout and brand palette
- `script.js` — mobile navigation and GSAP animations
- `assets/` — image assets folder
- `vercel.json` — Vercel settings

## Deploy on Vercel
1. Import the repository into Vercel.
2. Framework Preset: Other.
3. Leave build command empty.
4. Output Directory: `.`
5. Deploy.

Open `index.html` locally for quick preview.
